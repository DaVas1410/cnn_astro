turbulens

Predict fractal-turbulence parameters (k_min, k_max, sigma, beta) from a radio-astronomy FITS cube or a synthetic 2D image, with a deep-ensemble CNN or classical spectral estimators.

Model weights5 ensembles, multitask and single-target Dataset170k synthetic images with generator CodePackage, CLI, training pipeline GuideStep-by-step walkthrough

Try it

pip install "turbulens[image] @ git+https://github.com/wbandabarragan/cnn-turbulence.git"
hf download <MODEL_REPO_ID> --local-dir turbulens-ensembles

turbulens infer --input observation.fits --integrate LOW:HIGH --real-data \
    --method cnn --model auto --output-root turbulens-ensembles

No model needed for the classical estimators: --method fft-powerlaw works on any real observation. --real-data is required for real telescope data.
