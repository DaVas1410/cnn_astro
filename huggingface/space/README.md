# turbulens

Predict fractal-turbulence parameters (`k_min`, `k_max`, `sigma`, `beta`) from a radio-astronomy
FITS cube or a synthetic 2D image, with a deep-ensemble CNN or classical spectral estimators.

Source: https://github.com/wbandabarragan/cnn-turbulence
