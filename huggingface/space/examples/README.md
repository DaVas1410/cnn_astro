# Example inputs

Four real GASS HI survey fields (125x125 pixels, velocity axis), for trying `turbulens` on real
telescope data. Source: [GASS survey](https://www.parkes.atnf.csiro.au/research/GASS/), Parkes
Radio Telescope.

- `gass_300_14_1774393529.fits.gz` — Chamaeleon molecular cloud in HI, 10x10 deg.
- `gass_314_-28_1774393621.fits.gz` — Edge of the Chamaeleon molecular cloud, 10x10 deg.
- `gass_0_0_1774393774.fits.gz` — 10 deg above the Galactic Center.
- `gass_0_-10_1774394180.fits.gz` — 10 deg below the Galactic Center.

Remember `--real-data` (checked by default in this Space's UI) for any of these.
