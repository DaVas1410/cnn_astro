# Archive

Earlier stages of the project, kept for reference. The current code is
[`cPhysPlus/turbulens`](https://github.com/cPhysPlus/turbulens).

| Folder | Stage | Git tag |
|---|---|---|
| `v0_classification/` | CNN classification of parameter bins | `v0-classification` |
| `v1_lightweight_regression/` | First regression framework | `v1-lightweight-regression` |
| `v2_single_parameter/` | Separate `k_min`, `k_max`, `sigma` models | `v2-single-parameter` |
| `v3_joint_regression/` | Loss benchmark, joint regression, backbone comparison | `v3-joint-regression` |
| `v4_ensemble_and_kmax_bug/` | Deep ensemble, `k_max` bug fix, MC dropout | `v4-ensemble-kmax-fix` |
| `data_generation/` | pyFC dataset generator (still used to make the training data) | — |
| `observational_data/` | GASS HI cubes | — |

`git checkout <tag>` shows the repository as it was at that stage.
