User Guide
==========

Running `turbulens` on your own data. Start with :doc:`/getting_started`
for a first run.

- :doc:`cli`: every command and option.
- :doc:`python_api`: the same workflow as a library.
- :doc:`inputs`: supported formats, channel selection and spectral axes.
- :doc:`outputs_provenance`: the output table, its metadata and file
  formats.
- :doc:`pretrained_models`: the published ensembles, downloading,
  caching, version pinning, and using your own.
- :doc:`interpreting_results`: when to trust a prediction and what each
  parameter means on real data.
